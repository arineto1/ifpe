QUESTÃO 1

Considere as seguintes assertivas a respeito do papel do CSS3 e da separação de responsabilidades no desenvolvimento web moderno:

I. A regra fundamental da arquitetura web estabelece a estrita separação entre a estrutura semântica do documento (gerida pelo HTML) e sua apresentação visual (gerida pelo CSS), garantindo facilidade de manutenção, reuso de código e otimização de carregamento.

II. O uso do atributo style diretamente nas tags HTML (estilo inline) constitui a abordagem recomendada para ambientes de produção, por acelerar o processamento do navegador ao evitar requisições HTTP adicionais.

III. A inclusão de uma folha de estilo externa através do elemento <link rel="stylesheet"> inserido no <head> da página representa o padrão profissional para o desenvolvimento de aplicações web.

Quais assertivas estão corretas?

Resolução e Comentários (Gabarito: C)

A arquitetura do desenvolvimento web baseia-se na divisão clara entre a camada de estrutura/significado (HTML) e a camada de apresentação visual (CSS).

• Assertiva I (Correta): A separação de responsabilidades melhora a manutenção do código, viabiliza o reuso de folhas de estilo em múltiplas páginas e otimiza o carregamento dos arquivos pelo navegador.

• Assertiva II (Incorreta): A aplicação de estilos inline via atributo style dificulta a manutenção centralizada e quebra a reutilização do código, sendo considerada uma má prática no desenvolvimento profissional.

• Assertiva III (Correta): A inclusão externa mediante o elemento <link rel="stylesheet"> posicionado no <head> é o padrão profissional absoluto adotado para garantir a independência dos arquivos e o aproveitamento do cache do navegador.

QUESTÃO 2

Assinale a alternativa que preenche corretamente as lacunas do texto abaixo, referente às formas de inclusão de regras CSS em documentos HTML.

A inclusão de regras de estilo pode ocorrer de três formas distintas no documento web. O método ________ consiste na aplicação de regras através do atributo style diretamente na tag HTML, sendo considerado uma má prática para ambientes de produção por dificultar a manutenção do código. O método ________ utiliza a tag <style> posicionada no cabeçalho do documento, sendo indicado apenas para testes rápidos ou páginas isoladas. Por fim, a vinculação de um arquivo CSS ________, realizada mediante o elemento ________ inserido na seção <head>, é o padrão profissional absoluto.
Resolução e Comentários (Gabarito: B)

O CSS3 oferece três métodos para a integração de regras estilísticas a um documento HTML:

1. Inline: Utiliza o atributo style="..." diretamente nas tags do corpo do documento HTML, o que compromete a manutenibilidade e o reuso.

2. Interno: Utiliza o elemento <style> localizado na seção <head>, sendo adequado para testes pontuais ou protótipos.

3. Externo: Utiliza um arquivo com extensão .css vinculado ao documento via tag <link rel="stylesheet" href="..."> no <head>, estabelecendo a abordagem padronizada da indústria.

A sequência correta das lacunas é: inline — interno — externo — <link>.

1. Seletor Universal (*)
2. Seletor de Tipo (p)
3. Seletor de Classe (.cartao)
4. Seletor de ID (#topo-pagina)

Associe os seletores da coluna acima às suas características operacionais descritas a seguir:

(   ) Destinado à identificação e estilização exclusiva de um único elemento específico dentro da página web.

(   ) Seleciona e aplica regras de estilo a todas as instâncias de um determinado elemento estrutural da marcação.

(   ) Atinge indistintamente todos os elementos do documento HTML, sendo amplamente empregado na implementação de resets de margens e preenchimentos.

(   ) Define um conjunto de regras reutilizável que pode ser atribuído a múltiplos elementos ao longo da estrutura da página.

A sequência correta do preenchimento dos parênteses, de cima para baixo, é:

Resolução e Comentários (Gabarito: A)

• (4) O seletor de ID (#topo-pagina) é utilizado para identificar de maneira exclusiva um único elemento da página, devendo ser único no documento.

• (2) O seletor de tipo ou tag (p) atinge todas as ocorrências de um determinado elemento estrutural no documento HTML.

• (1) O seletor universal (*) abrange a totalidade dos elementos presentes no DOM, sendo a ferramenta padrão para reinicialização de margens e preenchimentos (reset).

• (3) O seletor de classe (.cartao) define um grupo de regras reutilizável que pode ser atribuído a múltiplos elementos da marcação.

QUESTÃO 4

Analise a estrutura HTML e as regras CSS3 apresentadas a seguir:

HTML
<header id="cabecalho-principal" class="topo">
  <h1 class="titulo">Estações do Ano</h1>
</header>
CSS
header h1 { color: blue; }
#cabecalho-principal .titulo { color: red; }
.topo h1 { color: green; }
h1 { color: yellow; }

Com base no mecanismo de cálculo de especificidade do CSS3, assinale a alternativa que indica a cor final assumida pelo texto do elemento <h1>:

Resolução e Comentários (Gabarito: B)

O cálculo de especificidade no CSS3 segue a hierarquia de pontuação (Inline, ID, Classe, Tipo):

• h1: 1 elemento de tipo (especificidade 0, 0, 0, 1 = 1 ponto).

• header h1: 2 elementos de tipo (especificidade 0, 0, 0, 2 = 2 pontos).

• .topo h1: 1 classe e 1 elemento de tipo (especificidade 0, 0, 1, 1 = 11 pontos).

• #cabecalho-principal .titulo: 1 ID e 1 classe (especificidade 0, 1, 1, 0 = 110 pontos).

Como o seletor com ID possui peso esmagadoramente superior (100 pontos por ID contra 10 por classe e 1 por tag), a regra vencedora é #cabecalho-principal .titulo, aplicando a cor Red.

QUESTÃO 5

A respeito dos conceitos de Cascata, Herança e Especificidade no CSS3, assinale a alternativa correta:

Resolução e Comentários (Gabarito: C)

• (A) Incorreta: Em caso de empate rigoroso na especificidade (cascata), prevalece a regra declarada por último no arquivo.

• (B) Incorreta: Propriedades estruturais do Box Model (margin, padding, border) não são herdadas automaticamente pelos elementos filhos.

• (C) Correta: A herança no CSS transmite naturalmente propriedades tipográficas e de texto (como fonte, cor do texto, alinhamento) dos pais aos seus descendentes.

• (D) Incorreta: O seletor universal (*) possui especificidade nula (0 pontos), sendo superado por qualquer seletor de tag (1 ponto).

• (E) Incorreta: O estilo inline possui especificidade de 1000 pontos, superando em muito a classe (10 pontos).

QUESTÃO 6

Considere o seguinte trecho de marcação HTML5 utilizado no desenvolvimento de uma interface com cartões informativos:

<header id="cabecalho-principal">
  <h1>As Estações do Ano no Hemisfério Sul</h1>
  <p>Exemplo prático de estilização e classes temáticas em CSS3</p>
</header>
<main>
  <article class="card-estacao primavera">
    <span class="tag-periodo">Setembro a Dezembro</span>
    <h2>Primavera</h2>
    <p>Conhecida como a estação das flores...</p>
  </article>
</main>

Em relação às características semânticas e estruturais desse trecho, considere as afirmativas:

I. O elemento <header> utiliza o atributo id="cabecalho-principal" para atribuir uma identificação única à seção de cabeçalho da página.

II. Cada cartão de estação é encapsulado pela tag semântica <article>, combinando a classe base .card-estacao com a classe temático-modificadora .primavera.

III. O elemento <main> deve encapsular os elementos <header> e <footer> para garantir a correta aplicação dos estilos CSS globais.

Quais afirmativas estão corretas?

Resolução e Comentários (Gabarito: C)

• Afirmativa I (Verdadeira): O elemento <header> é o cabeçalho estrutural e utiliza o ID único cabecalho-principal para formatação pontual.

• Afirmativa II (Verdadeira): O elemento <article> define um conteúdo autocontido e reutilizável, aplicando classes múltiplas para separar a estrutura base (.card-estacao) e o tema específico (.primavera).

• Afirmativa III (Falsa): Na arquitetura semântica do HTML5, o elemento <main> representa exclusivamente o conteúdo central da página, devendo ser elemento irmão de <header> e <footer>, e não pai deles.

QUESTÃO 7

Considere o trecho de código CSS3 referente ao agrupamento de regras de estilização global:

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

Assinale a alternativa que explica corretamente a função e o impacto da declaração box-sizing: border-box; no dimensionamento dos elementos da página:

Resolução e Comentários (Gabarito: B)

No modelo de caixa padrão do CSS (content-box), a largura (width) informada refere-se apenas à área do conteúdo, fazendo com que o preenchimento (padding) e as bordas (border) somem-se por fora, inflando o tamanho total do elemento e frequentemente quebrando layouts responsivos.

Ao definir box-sizing: border-box;, o navegador passa a embutir o padding e as bordas dentro da largura e altura declaradas, facilitando o cálculo dimensional.

QUESTÃO 8

Analise a regra CSS3 a seguir, projetada para controlar o comportamento dinâmico de cartões informativos ao passar o cursor do mouse:

.card-estacao {
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.card-estacao:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 16px rgba(0, 0, 0, 0.1);
}

Sobre os efeitos gerados por essas regras na interação com a interface, considere as afirmativas:

I. A pseudo-classe :hover atua quando o usuário posiciona o ponteiro do mouse sobre o elemento associado à classe card-estacao.

II. A declaração transform: translateY(-4px); provoca o deslocamento vertical do cartão em 4px para cima.

III. A propriedade transition determina que as alterações de transformação e sombra ocorram de forma gradual ao longo de 0,2 segundos.

Quais afirmativas estão corretas?

Resolução e Comentários (Gabarito: E)

• Afirmativa I (Correta): A pseudo-classe :hover é disparada quando o cursor do mouse é posicionado sobre a área do elemento alvo.

• Afirmativa II (Correta): No eixo cartesiano do navegador, valores negativos em translateY movem o elemento para cima no plano vertical, gerando a sensação de elevação de 4px.

• Afirmativa III (Correta): A propriedade transition interpola suavemente as propriedades de transformação e sombra durante o tempo de 0.2s com aceleração suave (ease).

Todas as três afirmativas estão corretas.

QUESTÃO 9

Considere a diferença sintática entre os dois seletores CSS3 apresentados abaixo:

Seletor A
.primavera .tag-periodo {
  background-color: #d1fae5;
}
Seletor B
.primavera.tag-periodo {
  background-color: #d1fae5;
}

Assinale a alternativa que descreve corretamente a diferença operacional entre os Seletores A e B:

Resolução e Comentários (Gabarito: A)

• Seletor A (.primavera .tag-periodo): O espaço atua como combinador de descendência. O navegador seleciona elementos com a classe tag-periodo que estejam aninhados/contidos dentro de um elemento ancestral com a classe primavera.

• Seletor B (.primavera.tag-periodo): Sem o espaço, trata-se de um seletor composto (channing). Ele atinge nós HTML que contenham obrigatoriamente ambas as classes no mesmo elemento (ex: <span class="primavera tag-periodo">).

QUESTÃO 10

Na implementação do estilo visual para o cartão do inverno em uma aplicação web, inseriu-se o seguinte bloco CSS3:

inverno {
  border-left-color: #0284c7;
}

inverno h2 {
  color: #0369a1;
}

.inverno .tag-periodo {
  background-color: #e0f2fe;
  color: #075985;
}

Sabendo que o elemento HTML correspondente foi marcado como <article class="card-estacao inverno">, assinale a alternativa correta quanto ao resultado da renderização:

Resolução e Comentários (Gabarito: B)

No CSS3, seletores de classe exigem obrigatoriamente o prefixo de ponto (.inverno). Nomes grafados sem prefixo são interpretados como seletores de tipo (tags HTML).

Como a tag <inverno> não existe no documento HTML (o elemento real é <article class="card-estacao inverno">), as duas primeiras regras falham silenciosamente. A terceira regra (.inverno .tag-periodo) é aplicada normalmente pois contém o ponto indicador de classe.
