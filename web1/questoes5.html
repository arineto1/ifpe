Questão 01 Banca FAURGS • Desenvolvimento Web

Considere as afirmações abaixo, relativas ao contêiner <form> e aos métodos de envio de dados em formulários na linguagem HTML5.

I - O atributo action especifica o endereço (URL ou endpoint) para onde os dados coletados no formulário deverão ser despachados após a submissão.

II - O método GET anexa os dados transmitidos diretamente na URL da requisição, sendo o método recomendado para o envio de dados sensíveis, como senhas e dados bancários.

III - O método POST empacota os dados no corpo (body) da requisição HTTP, impedindo que os dados fiquem visíveis na URL do navegador, sendo essencial para formulários de cadastro e login.

Quais estão corretas?

Gabarito Comentado: Opção (D)

A análise funcional das afirmações revela o papel do contêiner <form> e dos verbos HTTP na Web. A afirmação I está correta porque o atributo action é responsável por declarar o destino final dos dados submetidos pelo usuário, apontando para o script ou endpoint do servidor de aplicação que processará a requisição. A afirmação II está incorreta porque o método GET concatenará os pares de chave e valor diretamente na URL da página, tornando as informações totalmente expostas na barra de endereços, nos registros de histórico e nos logs de servidores de proxy. Essa exposição torna o método GET estritamente contraindicado para o envio de dados sensíveis ou confidenciais, devendo ser utilizado primordialmente para operações de consulta ou busca legíveis. A afirmação III está correta pois o método POST encapsula os dados dentro do corpo da mensagem HTTP, garantindo que valores como senhas e dados cadastrais não sejam exibidos na URL, sendo o padrão para operações que alteram o estado da aplicação no backend.

Gabarito Comentado: Opção (B)

A integração adequada entre a tag <label> e os elementos de entrada garante a acessibilidade para leitores de tela e a usabilidade em dispositivos móveis ou de toque. O mecanismo de amarração do HTML5 exige que o atributo for do elemento <label> referencie rigorosamente o identificador único definido no atributo id do elemento <input> correspondente. Questão 03 Banca FAURGS • Desenvolvimento Web

Um desenvolvedor Web construiu um formulário de cadastro contendo diversos campos de entrada. Durante os testes de integração com o servidor de aplicação, constatou-se que um dos campos preenchidos pelo usuário no navegador não teve seu valor incluído na requisição HTTP no momento da submissão.

Considerando as regras de especificação do HTML5, a ausência de qual atributo na tag <input> causou a não transmissão do dado ao servidor?

Gabarito Comentado: Opção (C)

O atributo name funciona como o identificador da variável que transporta o dado do cliente para o servidor. Quando o navegador realiza a leitura dos campos contidos dentro de um contêiner <form> no momento do envio, ele constrói um conjunto de dados conhecido como form data set. Apenas os controles de entrada que possuem o atributo name devidamente preenchido são incluídos nessa estrutura. A ausência de name faz com que o valor digitado pelo usuário seja totalmente desconsiderado no fluxo de montagem do pacote HTTP, fazendo com que o servidor receba uma requisição sem a chave correspondente. Atributos como id e placeholder servem, respectivamente, para manipulação via CSS/JavaScript/rótulos e para exibição de texto de ajuda visual dentro do campo, não interferindo na transmissão das variáveis de backend.

Questão 04 Banca FAURGS • Desenvolvimento Web

Gabarito Comentado: Opção (B)

A modelagem de interfaces de escolha no HTML5 diferencia-se pelo tipo de dado esperado. Quando a regra de negócio exige que o usuário escolha exatamente um único item dentro de um conjunto exclusivo de opções, a ferramenta gráfica correta é o radio button (type="radio"). Para que o navegador compreenda que múltiplos botões de rádio pertencem ao mesmo grupo de exclusão mútua — garantindo que a marcação de uma opção desmarque automaticamente a opção anterior —, todos os botões desse grupo precisam compartilhar obrigatoriamente exatamente o mesmo valor no atributo name. A alternativa A está incorreta pois o tipo checkbox permite seleções múltiplas independentes; a alternativa C inverte a lógica ao atribuir ao botão de rádio a capacidade de seleção múltipla; a alternativa D comete um erro de sintaxe ao citar selected, que pertence a <option>, em vez de checked; e a alternativa E confunde um controle de escolha pré-definida com um campo de texto livre multilinha.

Questão 05 Banca FAURGS • Desenvolvimento Web

O HTML5 fornece atributos de controle que alteram o comportamento de edição e submissão de campos em formulários, como readonly e disabled. Assinale a alternativa que descreve de forma correta a diferença de comportamento entre esses dois atributos.

Gabarito Comentado: Opção (B)

A especificação do HTML5 estabelece diferenças comportamentais marcantes entre os atributos booleanos readonly e disabled. O atributo readonly impede a alteração direta do valor do campo pelo usuário final, mas preserva a sua participação ativa no formulário. Consequentemente, o elemento com readonly continua sendo focalizável via navegação por teclado e seu valor é empacotado e enviado normalmente ao servidor durante a submissão. Em contrapartida, o atributo disabled inativa o elemento por completo. Um controle marcado como disabled não recebe foco, não pode ser editado e tem sua participação revogada na construção do conjunto de dados de submissão, fazendo com que o navegador omita totalmente seu nome e seu valor do pacote HTTP despachado ao servidor.

Questão 07 Banca FAURGS • Desenvolvimento Web

Considere o trecho de código HTML5 extraído de uma aplicação Web de gestão de projetos: 

<div>
    <label for="campo-arquivo">Resumo do Projeto (PDF): </label>
    <input type="file" id="campo-arquivo" name="documento_resumo" accept=".pdf">
</div>
<div>
    <label for="campo-horas">Dedicação Semanal Estimada (Horas):</label>
    <input type="range" id="campo-horas" name="horas_semanais" min="2" max="20" value="4" step="2">
</div>

Em relação aos elementos e atributos do trecho acima, considere as seguintes afirmações:

I - O atributo accept=".pdf" no elemento <input type="file"> restringe os tipos de arquivos aceitos na caixa de diálogo de seleção do sistema operacional para extensões .pdf.

II - O elemento <input type="range"> renderiza um controle deslizante cujos limites mínimos, máximos, valor inicial e intervalo de variação são definidos pelos atributos min, max, value e step, respectivamente.

III - Para realizar o envio com sucesso de arquivos através do elemento <input type="file">, o formulário pai deve obrigatoriamente utilizar o método GET.

Quais estão corretas?

Gabarito Comentado: Opção (C)

A análise dos controles específicos revela a veracidade das afirmações I e II. A afirmação I está correta pois o atributo accept especifica os tipos de arquivos que o controle de upload (type="file") deve aceitar, orientando a caixa de diálogo do sistema operacional a filtrar as extensões desejadas, como .pdf. A afirmação II está correta pois o elemento <input type="range"> renderiza um controle deslizante numérico configurado via atributos de limite e passo (min, max, value e step). A afirmação III está incorreta porque o envio de arquivos requer o transporte de payloads binários complexos, o que exige obrigatoriamente a utilização do método POST combinado com o tipo de codificação multipart/form-data no formulário pai, sendo o método GET completamente inapropriado para a transferência de arquivos.

Questão 08 Banca FAURGS • Desenvolvimento Web

Na construção de formulários extensos e complexos, o HTML5 disponibiliza elementos estruturais específicos para promover o agrupamento semântico e visual de seções da interface. Assinale a alternativa que indica corretamente a combinação de elementos responsável por agrupar um conjunto de campos relacionados e fornecer um título semântico a esse grupo, respectivamente.

Gabarito Comentado: Opção (B)

A estruturação semântica de formulários no HTML5 utiliza a combinação dos elementos <fieldset> e <legend> para organizar visual e conceitualmente seções de dados relacionadas em uma interface. O elemento <fieldset> atua como o contêiner delimitador que agrupa logicamente os controles de entrada pertinentes a uma determinada etapa ou categoria do cadastro. O elemento <legend>, por sua vez, deve ser posicionado imediatamente após a abertura do <fieldset> para definir o título semântico e visível daquela seção. Essa combinação melhora significativamente a experiência de navegação e possibilita que tecnologias assistivas anunciem o contexto do grupo de campos ao usuário durante o preenchimento.

Gabarito Comentado: Opção (B)

A especificação HTML5 define elementos nativos para a seleção de listas e a entrada de textos longos. A construção de menus suspensos do tipo dropdown, onde o usuário seleciona uma opção entre diversas alternativas pré-definidas, é realizada pelo contêiner <select>, que envolve múltiplos elementos de opção <option>. Questão 10 Banca FAURGS • Desenvolvimento Web

Análise os botões definidos no bloco de ações de um formulário HTML5 descrito a seguir: 

<div>
    <button type="submit">Enviar Inscrição</button>
    <button type="reset">Limpar Tudo</button>
</div>

Com relação ao comportamento nativo desses botões quando acionados pelo usuário no navegador, assinale a alternativa correta.

Gabarito Comentado: Opção (C)

Os botões de ação nativos dentro de um formulário executam comportamentos predefinidos no navegador conforme o valor atribuído ao atributo type. O botão configurado com type="submit" atua como o gatilho de validação e envio do formulário. Ao ser pressionado, o navegador interrompe temporariamente o envio para checar todas as regras de validação nativas declaradas nos campos; se nenhuma violação for encontrada, os dados são empacotados e transmitidos para o destino declarado no atributo action. O botão configurado com type="reset" possui a função exclusiva de restaurar o estado visual de todos os controles contidos no formulário aos seus valores iniciais originais, limpando dados digitados e redefinindo caixas de seleção.
